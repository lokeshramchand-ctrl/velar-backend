# Offline training/fine-tuning stack. Only needed to run training/train.py
# or training/finetune.py (and evaluation/metrics.py, which they both use)
# directly on your own machine - none of this is imported by the live API
# (app.py's import graph never touches training/ or evaluation/), and it is
# deliberately NOT installed in the production Docker image (see Dockerfile)
# to keep the deployed image small and its dependency-scan/CVE surface
# limited to what's actually running in production.
#
# Usage:
#   pip install -r requirements.txt -r requirements-training.txt
